# 현재 구현 상태

최종 갱신: 2026-05-17

이 문서는 현재까지의 주요 변경사항을 빠르게 확인하기 위한 기준 문서다. 세부 설계 원문은 `GAME_DESIGN.md`, 기술 방향은 `TECH_DESIGN.md`, 자산 규칙은 `docs/ASSET_GUIDE.md`를 함께 참고한다.

## 프로젝트 구조

- 실행 기준은 여전히 `web/app.js` 단일 런타임이다.
- 빌드와 개발 서버는 Vite를 사용한다.
- 서버는 Node/Express 기반이며, 정적 빌드 산출물과 기본 API를 제공한다.
- 게임 로직은 기존 Vanilla JS 모듈 구조를 유지하고, 렌더링은 PixiJS WebGL로 점진 이관 중이다.
- 데이터는 JSON을 우선 사용하고, 이후 서버 저장 데이터는 SQLite로 확장하는 방향이다.

## 실행

```bash
npm install
npm run dev
npm run build
npm run server
```

개발 서버는 기본적으로 `http://localhost:3000`에서 사용한다.

## 역사 시나리오 모드

- 홈 화면의 `역사 시나리오` 메뉴는 바로 전투를 시작하지 않고 시나리오 선택 화면으로 이동한다.
- 시나리오 선택 화면은 5x2 카드 배열을 사용한다.
- 카드는 타이틀과 연도만 표시하며, 별도 시작 버튼 없이 카드를 선택하면 실행된다.
- 현재 활성 시나리오는 `포위 - 칸나에 전투` 하나다.
- 나머지 시나리오는 준비 중 카드로 표시한다.

준비 중인 시나리오 목록:

- 망치와 모루 - 가우가멜라 전투
- 매복 - 박망파 전투
- 거짓 후퇴 - 칼카강 전투
- 수공 - 흥화진/귀주 대첩
- 복합 전술 - 주필산 전투
- 화공 - 이릉 대첩
- 추가 준비 중 카드 3종

## 시나리오 선택 자산

- 원본 아이콘: `web/assets/ui/scenario_icons.png`
- 크롭 결과: `web/assets/ui/scenario_icons_cropped.png`
- 크롭 결과는 7개의 256x256 아이콘을 가로로 이어 붙인 스프라이트 시트다.
- CSS에서 `background-position`으로 카드별 아이콘을 선택한다.

아이콘 순서:

1. 칸나에 전투
2. 가우가멜라 전투
3. 박망파 전투
4. 칼카강 전투
5. 흥화진/귀주 대첩
6. 주필산 전투
7. 이릉 대첩

## 칸나에 전투

칸나에 전투는 첫 번째 실제 구현 대상 역사 시나리오다.

관련 파일:

- 시나리오 데이터: `web/data/scenarios/cannae.json`
- 고정 지형 데이터: `web/data/scenarios/cannae_terrain.json`
- 지형 생성 스크립트: `scripts/generate-cannae-terrain.mjs`
- 지형 확인 도구: `web/terrain-json-viewer.html`

지형 생성:

```bash
npm run scenario:terrain:cannae
```

### 지형

- 맵 크기는 240x160 타일이다.
- 북쪽에는 넓게 휘어진 아우피두스 강이 있다.
- 중앙은 평원이다.
- 남쪽에는 초지, 산지, 산악 기반 지형이 있다.
- 하단 중앙에는 완만하게 휘어진 도로가 있다.
- 평지와 산지 경계는 노이즈를 적용해 완전한 직선이 되지 않게 했다.

### 병력

카르타고군:

- 한니발: 보병 15,000명, 기합, 중앙 유인 지휘
- 마고: 보병 12,500명, 사수, 중앙 유인
- 기스코: 보병 12,500명, 사수, 중앙 유인
- 하스드루발: 기병 5,000명, 기합, 북쪽 기병
- 마하르발: 기병 5,000명, 기합, 남쪽 기병

로마군:

- 아이밀리우스 파울루스: 보병 25,000명, 사수
- 세르빌리우스: 보병 25,000명, 사수
- 미누키우스: 보병 30,000명, 사수
- 젊은 스키피오: 기병 3,000명, 기합
- 바로: 기병 3,000명, 기합

### 밸런스 보정

- 역사 시나리오에서는 병력 조정 화면을 사용하지 않는다.
- 칸나에의 아군 보병은 시나리오 전용 방어력 보정을 받는다.
- 한니발 부대는 다른 아군 보병보다 더 높은 방어력 보정을 받는다.
- 사수 스킬의 방어 효과는 강화되어 있다.
- 한니발의 기합 공격 보너스는 추가로 강화되어 있다.

## 칸나에 퀘스트 흐름

### 1단계: 결전을 앞둔 진형 정비

- 대화는 로마군이 새롭게 군단병을 소집해 집결했고, 결전을 앞두고 진형을 정비해야 한다는 내용이다.
- 아군은 좌측 끝에서 시작한다.
- 모든 아군 진형은 보통 간격으로 시작한다.
- 목표는 얇은 직사각형 집결지 안에 모든 아군 진형이 들어와 정지 상태를 유지하는 것이다.
- 로마군은 모든 부대를 좁은 횡대로 배치하고 빠른 속도로 지정 집결선까지 이동한다.
- 로마군 집결 지역은 화면에 표시하지 않는다.
- 1단계 완료 전에 로마군이 피해를 받으면 기존 배치 지침보다 공격 행동을 우선한다.

### 2단계: 유인과 인내

- 대화는 압도적인 로마군 규모에 두려워하는 장수와 자신감 있는 한니발의 대화로 구성한다.
- 중앙 보병은 지정된 후퇴선까지 유인해야 한다.
- 사수 스킬 사용은 퀘스트 조건에 포함하지 않는다.
- 로마 기병은 공격하지 않고 지정 위치를 지킨다.
- 로마 기병은 병력이 50% 이하가 되면 패주한다.
- 로마 보병은 촘촘한 간격과 보통 속도로 진군한다.
- 로마 보병은 자신의 진행 방향과 가장 가까운 아군 진형을 개별적으로 추적한다.

### 3단계: 독 안에 든 쥐

- 기존 포위 대화 내용을 유지한다.
- 로마군 혼란도는 즉시 0.7 이상으로 상승한다.
- 로마 보병은 지정된 한 점이 아니라 가장 앞에 있는 로마 보병 위치를 기준으로 뭉치려 한다.
- 지도에는 별도 포위 지점을 표시하지 않는다.
- 적군 전체에 80% 이상 피해를 주면 완료된다.

## 퀘스트 UI

- 퀘스트 박스를 클릭하면 현재 단계의 주요 목표 영역을 5초 동안 표시한다.
- 1단계 수행 중에는 집결 지역을 항상 표시하지 않는다.
- 시나리오 진행 중에는 일반 전투 승패와 별개로 퀘스트 조건을 우선한다.

## 지형 JSON 뷰어

- `web/terrain-json-viewer.html`은 지형 JSON을 색상 타일로 확인하는 개발용 페이지다.
- 로컬 파일로 직접 열면 브라우저 CORS 제한이 발생할 수 있으므로 Vite 개발 서버에서 접근한다.
- 접근 경로: `http://localhost:3000/terrain-json-viewer.html`

## 전투/유닛 주요 변경

- 데미지는 실제 병사 수 피해로 처리한다.
- 화면의 유닛 1개는 병사 100명을 압축 표시한 것이다.
- HUD 병력바, 표시 병력, 전투 결과 통계는 유닛 사망 수가 아니라 실제 누적 피해 기준으로 계산한다.
- 기병 병과를 추가했다.
- 기병은 별도 스프라이트 시트를 사용하며, 보병과 다른 인구 비용, 이동, 방어, 공격 규칙을 가진다.
- 기병은 원거리 공격을 하지 않는다.
- 병력 조정에서는 한 장수가 보병 또는 기병 중 하나만 선택할 수 있다.

## 지형/렌더링 주요 변경

- 1x1 지형 타일은 미세 경계선 완화를 위해 48x24 규격으로 리사이즈했다.
- 기존 1x1 지형 타일은 `_backup_tile_1x1_20260515`에 백업되어 있다.
- 평지에는 약 2% 확률로 오브젝트 타일이 배치된다.
- FOG는 화면보다 큰 렌더 텍스처를 사용해 가장자리 블러 문제가 줄어들도록 조정했다.
- 유닛 정지 상태의 방향 진동을 줄이기 위해 시각 방향 갱신에 dead zone, hysteresis, 변경 쿨다운을 적용했다.
- 정지 직후에는 개별 순간 속도보다 진형 방향을 우선해 방향을 유지한다.

## 홈/UI 주요 변경

- 홈 화면 배경은 JPG 압축본을 사용한다.
- 홈 화면 배경 후보에서 `MAIN2`는 제외했다.
- 홈 배경 투명도는 0.4 수준으로 낮췄다.
- 우측 컨트롤 버튼은 포커스를 받지 않도록 해 단축키 입력 방해를 줄였다.
- 게임 화면 진입 시 로딩 마스크를 표시하고, 주요 요소 로딩 후 서서히 사라지게 했다.
- 장수 프로필 영역에는 더 뚜렷한 석재 질감의 inner bevel 효과를 적용했다.
