# 에셋 가이드

## 기준

지형 에셋은 최대 줌 기준 타일 실제 크기인 `24x12px`에 맞춘다. 과거의 대형 이미지 제작 후 축소 방식은 사용하지 않는다.

## 권장 분류

```text
web/assets/
  terrain_tiles_v3/
  portraits/
  ui/
  effects/
```

## PixiJS 전환 시 권장 사항

- 같은 계열의 타일과 효과는 스프라이트시트/아틀라스로 묶는다.
- 런타임 문자열 경로를 줄이고 에셋 매니페스트를 둔다.
- 픽셀아트는 nearest-neighbor 렌더링을 유지한다.
